# แดชบอร์ดผู้บริหาร - โรงงานเยื่อไผ่ (Bamboo Pulp Executive Dashboard)

แดชบอร์ดผู้บริหารแบบหน้าเว็บเดียว (static site) สำหรับโรงงานเยื่อไผ่ 3 แห่งในประเทศไทย:
**เพชรบูรณ์ · สงขลา · เชียงใหม่** แสดง KPI เชิงธุรกิจ (รายได้ กำไรขั้นต้น OTIF ความเสี่ยงการส่งมอบ
ต้นทุนต่อตัน ฯลฯ) พร้อมแผนที่และการ์ดสรุปรายโรงงาน

ข้อมูลทั้งหมดอ่านจากไฟล์ JSON เพียงไฟล์เดียว ไม่ต้องมี backend หรือ build step ใด ๆ

## โครงสร้างไฟล์

```
index.html          หน้าแดชบอร์ดหลัก
assets/style.css     ธีม สี และเลย์เอาต์ (รองรับโหมดสว่าง/มืด)
assets/app.js        โหลด data/dashboard.json แล้ววาดกราฟ/การ์ด/แผนที่ทั้งหมด
data/dashboard.json  ข้อมูล KPI และข้อมูลรายโรงงานทั้งหมด (แก้ไฟล์นี้เพื่ออัปเดตแดชบอร์ด)
```

## วิธีอัปเดตข้อมูล

แก้ไขค่าต่าง ๆ ใน `data/dashboard.json` แล้ว commit + push เท่านั้น ไม่ต้องแก้โค้ด:

- `meta` — ชื่อบริษัท ชื่อแดชบอร์ด เวลาที่อัปเดตล่าสุด
- `kpi_summary` — รายได้รวม (พร้อมข้อมูลย้อนหลังรายเดือนสำหรับกราฟเส้นเล็ก) อัตรากำไรขั้นต้น OTIF และคะแนนความเสี่ยงการส่งมอบ
- `sites[]` — ข้อมูลรายโรงงาน 3 แห่ง (กำลังผลิต สต็อก พลังงาน สุขภาพเครื่องจักร ความผิดปกติ ฯลฯ)
  - `map_position` คือพิกัด x,y บน viewBox แผนที่ขนาด 300x528 (โปรเจกต์จากพิกัดละติจูด/ลองจิจูดจริงของแต่ละจังหวัด ปรับตำแหน่งหมุดบนแผนที่ได้ที่นี่)
- `order_execution[]` — รายการคำสั่งซื้อ/งานผลิตที่กำลังดำเนินการ
- `performance_overview` — ผลผลิตจริงเทียบแผนส่งมอบรายวัน
- `waste_scrap` — ต้นทุนของเสีย/เศษวัสดุ แยกตามหมวด
- `net_energy_cost` — ต้นทุนพลังงาน (ไฟฟ้า/ไอน้ำ) ต่อตันรายวัน
- `unit_cost` — ต้นทุนวัตถุดิบและค่าโสหุ้ยต่อตันรายวัน

หน้าเว็บจะโหลดค่าจากไฟล์นี้ทุกครั้งที่เปิด/รีเฟรช ไม่มีการแคชฝั่งเซิร์ฟเวอร์

## รันดูตัวอย่างในเครื่อง

เบราว์เซอร์บล็อกการ `fetch()` ไฟล์ผ่าน `file://` จึงต้องรันผ่านเว็บเซิร์ฟเวอร์เล็ก ๆ:

```bash
cd /path/to/Dashboard
python3 -m http.server 8080
# เปิดเบราว์เซอร์ที่ http://localhost:8080
```

## Deploy ผ่าน GitHub Pages (ให้คนอื่นเปิดผ่านเว็บได้)

1. Push โค้ดนี้ขึ้น GitHub repository
2. ไปที่ **Settings → Pages**
3. เลือก **Source: Deploy from a branch** แล้วเลือก branch/โฟลเดอร์ที่มี `index.html` (เช่น `main` / root)
4. บันทึก แล้วรอสักครู่ ระบบจะให้ลิงก์ เช่น `https://<username>.github.io/<repo>/`
5. แชร์ลิงก์นี้ให้ผู้บริหาร/ทีมงานเปิดดูได้ทันที

ทุกครั้งที่แก้ `data/dashboard.json` แล้ว push ขึ้น branch ที่ตั้งค่า Pages ไว้ หน้าเว็บจะอัปเดตอัตโนมัติ
(อาจใช้เวลาสักครู่ให้ GitHub Pages build ใหม่)

## หมายเหตุ

- แผนที่ประเทศไทยในหน้าแดชบอร์ดเป็นรูปทรง 3 มิติที่โปรเจกต์จากเส้นขอบประเทศจริง (ย่อรายละเอียดเส้นขอบให้เรียบง่ายเพื่อความสวยงาม) ตำแหน่งหมุดคำนวณจากพิกัดละติจูด/ลองจิจูดจริงของแต่ละจังหวัด
- แผนที่ซูมเข้า/ออกได้ด้วยล้อเมาส์หรือปุ่ม +/− มุมขวาล่าง ลากด้วยเมาส์หรือนิ้วเพื่อเลื่อนมุมมอง และบีบนิ้ว (pinch) เพื่อซูมบนมือถือ/แท็บเล็ต กดปุ่มวงกลมลูกศรเพื่อรีเซ็ตกลับมุมมองเริ่มต้น
- กราฟใช้ไลบรารี [Chart.js](https://www.chartjs.org/) เวอร์ชัน 4.4.4 ซึ่งฝังไว้ในโปรเจกต์แล้ว (`assets/chart.umd.js`) ไม่ต้องพึ่งพา CDN ภายนอก เปิดใช้งานได้แม้ไม่มีอินเทอร์เน็ต (นอกเหนือจากฟอนต์ Google Fonts ซึ่งเป็นตัวเลือกเสริม)
- รองรับโหมดมืด/สว่าง ปุ่มสลับอยู่มุมขวาบนของหน้า
